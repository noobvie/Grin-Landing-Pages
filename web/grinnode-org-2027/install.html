Install in one line.

One address, two installers. The server looks at the program asking for it: curl and wget get the Linux installer, PowerShell gets the Windows one, and a browser gets this page. Prefer to read a script before running it? Each one has its own fixed address and a SHA256 checksum below.

Linux server — Grin Node Toolkit

  • Ubuntu 24.04+
  • Rocky 10+
  • AlmaLinux 10+
  • run as root
  • a fresh VPS is best

Connect to your server over SSH and paste:

root@vps: ~
curl -fsSL https://grinnode.org/install | sudo bash

Already logged in as root? Leave out sudo: curl -fsSL https://grinnode.org/install | bash

What the script does, and nothing more:

  1. Checks that it runs as root on Linux with apt-get or dnf.
  2. Installs git if it is missing.
  3. Downloads the toolkit from GitHub into /root/grin-node-toolkit. A toolkit already in that folder is left as it is.
  4. Starts the toolkit menu. The node itself is installed only when you choose it there (1) Build/Control Grin Node).

SHA256 of install.sh: see install.sh.sha256

Read it before you run it
download, check, read, run
curl -fsSLO https://grinnode.org/install.sh
curl -fsSL https://grinnode.org/install.sh.sha256 | sha256sum -c -
less install.sh
sudo bash install.sh

The source is also on GitHub: install.sh.

Options

Piped into bash, pass options after bash -s --:

install only, start the menu later
curl -fsSL https://grinnode.org/install | sudo bash -s -- --no-launch

--dir PATH installs somewhere other than /root/grin-node-toolkit. --no-launch installs without starting the menu. --branch NAME picks a branch other than main.

Install by hand instead
root@vps: ~
git clone https://github.com/noobvie/Grin-Node-Toolkit.git grin-node-toolkit
cd grin-node-toolkit
chmod +x grin-node-toolkit.sh scripts/*.sh
sudo ./grin-node-toolkit.sh

Windows — Grin Node Desktop

Work in progress — not ready for general use yet

A Windows wallet app that runs its own Grin node. Open PowerShell as Administrator and paste:

PS C:\>
irm https://grinnode.org/install | iex

What the script does:

  1. Picks D:\Grin, or C:\Grin, on a drive with at least 20 GiB free.
  2. Installs Git and Node.js LTS with winget if they are missing.
  3. Downloads the app from GitHub into that folder, or updates an existing copy.
  4. Starts the app, which opens in your browser.

SHA256 of install.ps1: see install.ps1.sha256

Read it before you run it
download, check, read, run
cd $env:USERPROFILE
iwr https://grinnode.org/install.ps1 -OutFile install.ps1 -UseBasicParsing
Get-FileHash install.ps1    # compare with the SHA256 above (case does not matter)
notepad install.ps1
iex (Get-Content install.ps1 -Raw -Encoding UTF8)

Run this in the Administrator PowerShell; without admin rights the script stops and asks you to.

The source is also on GitHub: install.ps1.

How one address serves both

Every request names the program that sent it (the User-Agent header). The server answers https://grinnode.org/install like this:

Asked byGets
PowerShell (Windows PowerShell 5.1, PowerShell 7)install.ps1 — Grin Node Desktop
curl, wgetinstall.sh — Grin Node Toolkit
a browser, anything elsethis page

The fixed addresses /install.sh and /install.ps1 always return the same script to everyone, with checksums at /install.sh.sha256 and /install.ps1.sha256. The older https://grin.money/install redirects here.
