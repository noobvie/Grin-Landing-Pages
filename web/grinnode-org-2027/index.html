anon@grinnode:~$ cat why_run_a_node.txt # 01 / Why run a node

A node is how you verify Grin for yourself.

Wallets are useful, but reachable full nodes are the network’s public backbone. They validate chain history, relay blocks and transactions, and give new users more peers to connect to.

  • Verify independently

    Your node checks chain rules directly instead of trusting another server’s view of the network.

  • Accept inbound peers

    A reachable Grin node helps other nodes discover, sync, and stay connected to the chain.

  • Improve resilience

    More independent operators means fewer fragile points and a healthier privacy-focused network.

Pick the path that matches your setup.

A Linux server for always-on public infrastructure, Umbrel for a box at home, or Grim on the computer you already own — three ways in, one network.

drwxr-x--- root vps linux_server/

Linux server path

Best for VPS operators, public services, snapshots, monitoring, and community infrastructure.

  1. Clone Grin Node Toolkit and run the interactive Bash menu — the manual walks through it.
  2. Build or install a node, then bootstrap chain data from a trusted snapshot.
  3. Publish API, file server, explorer, stats, mining, or wallet services as needed.

drwxr-xr-x user home docker_umbrel/

Docker / Umbrel

Best for a home server or Raspberry Pi, when you want a node without renting a VPS.

  1. Set up Umbrel on a home server or Raspberry Pi.
  2. Add the Umbrel community app store and install the Grin app (mainnet or testnet).
  3. The node runs in containers, syncs on its own, and comes with a web dashboard. Its compose files sit in the same repo if you run plain Docker.

-rwxr-xr-x user any_os desktop_grim

Desktop path (any OS)

Best when you want a wallet and a node in one app, with no server and no terminal.

  1. Download Grim from gri.mw — Windows, macOS, Linux or Android.
  2. Create or restore a wallet. Grim’s built-in node joins the network on its own, or you can point it at a node you run.
  3. Send and receive via Slatepack, explore history, manage multiple wallets.

anon@grinnode:~$ man grin # 06 / Why Grin

Why Grin is worth a node of your own.

Nine reasons, written for the people who keep it running — plain words, no hype, nothing you have to take on trust.

GRIN(1)Why GrinGRIN(1)

NAME

grin — private money your own machine can audit: hidden amounts, no addresses on chain, 60 GRIN a minute with no end date

REASONS

Nobody can print a coin your node did not expect
Grin’s developers set the reward at launch: 60 GRIN for each block, one block a minute on average. Since then it has lived in the consensus rules, and every node enforces it. A block that pays its miner one grin too many is simply rejected by your machine. There is no company to lobby, no token vote and no pause button. Changing the rule would take a hard fork that every operator would have to choose to run.
Private is the only setting
Some coins offer privacy as an option you have to remember to switch on. Grin has no transparent mode to fall back to. Every transaction, from a testnet experiment to rent money, carries hidden amounts and writes no addresses to the chain. The node you run relays and checks them all without learning how much anyone paid.
A chain that forgets what it no longer needs
When a coin is spent, cut-through drops the old output from the chain. Bitcoin’s history is past 600 GB and only grows; a pruned Grin node still fits in a few gigabytes, years after the 2019 launch. A small VPS (from about $20 a year) or an old PC in the corner is enough to verify everything yourself.
Quick to join
Since v5.2.0 (January 2024) new nodes download the chain state in parallel pieces (PIBD) instead of one long crawl. On a server, Grin Node Toolkit can start you from a chain snapshot as well, so a fresh node is useful in hours, not days.
No halvings to plan around
Where other coins cut the mining reward every few years, Grin pays the same 60 GRIN per block this year, next year and every year after. Miners and pool operators can plan with a number that never drops off a cliff.
Payments without a public address
A Grin payment is built by both wallets together with a Slatepack: a block of text you can paste in a chat, save as a file, show as a QR code, or let the wallets swap over Tor. Each side takes a turn, but not at the same moment. A slatepack address helps route and encrypt that exchange if you want one; it is never written to the chain.
Inflation falls by arithmetic
The same 60 GRIN a minute lands on a pile that keeps growing, so the yearly percentage shrinks on its own: about 13% in late 2026, a little lower every year after. It never reaches zero, and issuance never ends — no committee, no upgrade, just division.
Small enough to read
No scripting language, no tokens, a handful of transaction kinds. Grin’s four scheduled hard forks were all done by January 2021, and none have been planned since, so a node upgrade is rarely a race. An engineer can work through the core design in a weekend.
Copy the code. You can’t copy the clock.
Anyone can fork Grin’s source tonight. Their chain starts at block zero, empty. Grin carries every block mined since 15 January 2019, and that work cannot be done again — the hours have already been spent. Your node keeps a copy of the real history.
